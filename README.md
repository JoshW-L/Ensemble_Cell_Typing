
# Ensemble Cell Typing

![Pipeline Overview](images/Cell Typing pipeline.png)

## Overview
This repository contains R scripts for an ensemble-based cell typing pipeline. The method integrates multiple clustering and classification approaches to improve cell type annotation accuracy in single-cell RNA-seq data.

## Features
- **Quality Control**: Preprocessing and filtering of raw data.
- **Multiple Methods**: Implements several clustering and labeling strategies.
- **Ensemble Voting**: Combines predictions from different methods for robust cell type assignment.
- **Evaluation**: Provides metrics and visualization for method comparison.
